知识点 1：f-string，最好用的拼接方式

第 1 天我们用逗号或 + 拼接文字：

name = "Tom"
age = 18
print("Hello, " + name + "! You are", age, "years old.")

又是加号又是逗号，很容易写错。f-string 更简单：在引号前加一个 f，变量放进 {} 里。

name = "Tom"
age = 18
print(f"Hello, {name}! You are {age} years old.")
print(f"Next year you will be {age + 1}.")

输出：

Hello, Tom! You are 18 years old.
Next year you will be 19.

要点：

  • {} 里可以放变量，也可以放计算式
  • 不用管是文字还是数字，f-string 会自动转换
  • 保留小数：{bmi:.1f} 表示保留 1 位小数
bmi = 22.857142
print(f"Your BMI is {bmi:.1f}")   # Your BMI is 22.9

小实验：把 f"Hello, {name}!" 前面的 f 删掉，运行看看会输出什么。

知识点 2：字符串的常用操作

字符串就是一串字符，Python 给它准备了很多好用的工具。

word = "  Python  "

print(len(word))          # 10，空格也算字符
print(word.strip())       # "Python"，去掉两边的空格
print(word.upper())       # "  PYTHON  "，变大写
print(word.lower())       # "  python  "，变小写

.strip() 这种写在变量后面、带一个点的，叫做方法。读作「对 word 做 strip 操作」。

取出某个字符（索引）：

lang = "Python"
print(lang[0])    # P，第一个字符，从 0 开始数！
print(lang[1])    # y
print(lang[-1])   # n，-1 表示最后一个
 P   y   t   h   o   n
 0   1   2   3   4   5
-6  -5  -4  -3  -2  -1

判断是否包含：

email = "tom@example.com"
print("@" in email)       # True
print("#" in email)       # False

方法可以连着用，从左往右依次执行：

answer = "  YES "
print(answer.strip().lower())   # "yes"

这在处理用户输入时特别有用：用户可能多打了空格，或者大小写不统一。

知识点 3：逻辑运算 and / or / not

一个条件不够用时，可以组合多个条件。

运算 意思 什么时候是 True
and 并且 两边都是 True
or 或者 两边至少一个是 True
not 不是 把 True 变 False，False 变 True 
age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("You can enter.")

day = "Sunday"
if day == "Saturday" or day == "Sunday":
    print("It's the weekend!")

is_raining = False
if not is_raining:
    print("Let's go outside.")

连续比较：Python 允许这样写，和数学里一样：

bmi = 22
if 18.5 <= bmi < 24:
    print("Normal")

等价于 bmi >= 18.5 and bmi < 24，但更好读。

⚠️ 常见坑：

day = "Monday"
if day == "Saturday" or "Sunday":   # ❌ 永远是 True！
    print("Weekend")

or 右边的 "Sunday" 是一个非空字符串，Python 把它当成 True。必须写完整：day == "Saturday" or day == "Sunday"。

知识点 4：嵌套 if

if 里面还可以再放 if，注意每一层都要多缩进一级。

age = int(input("How old are you? "))

if age >= 18:
    has_id = input("Do you have an ID? (yes/no) ").strip().lower()
    if has_id == "yes":
        print("Welcome!")
    else:
        print("Please bring your ID.")
else:
    print("Sorry, adults only.")

读法：先看外层（是否成年），成年了再看内层（是否带证件）。

建议：嵌套不要超过 2～3 层，太深就很难读了。很多时候可以用 and 或 elif 把它拉平。

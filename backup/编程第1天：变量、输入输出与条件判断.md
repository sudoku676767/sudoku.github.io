## 第 0 步：准备环境（Ubuntu 26.04，约 15 分钟）

好消息：Ubuntu 已经自带 Python 3，不需要另外下载。

**1. 打开终端**：按 `Ctrl + Alt + T`。以后看到「在终端输入」，就是在这个黑色窗口里输入命令，然后按回车。

**2. 确认 Python 可用**：
```bash
python3 --version
```
看到类似 `Python 3.x.x` 的输出就对了。
> ⚠️ Ubuntu 上的命令是 **`python3`**，不是 `python`。网上很多教程写的是 `python`，你看到时自动换成 `python3` 即可。

**3. 安装两个以后会用到的工具**（会要求输入你的开机密码，输入时屏幕不显示字符，这是正常的）：
```bash
sudo apt update
sudo apt install python3-pip python3-venv
```

**4. 安装 VS Code**：
```bash
sudo snap install code --classic
```
也可以打开 Ubuntu 自带的「应用中心」，搜索 `Visual Studio Code` 安装。

**5. 建一个学习文件夹并用 VS Code 打开**：
```bash
mkdir ~/learn-python
cd ~/learn-python
code .
```
- `mkdir` = 新建文件夹，`~` 代表你的主目录（/home/你的用户名）
- `cd` = 进入文件夹
- `code .` = 用 VS Code 打开当前文件夹（`.` 代表「当前位置」）

**6. 安装 Python 插件**：VS Code 左侧点「扩展」图标（四个小方块）→ 搜索 `Python` → 安装微软（Microsoft）出品的那个。

**7. 写第一个程序**：在 VS Code 里新建文件 `hello.py`，写入：
```python
print("Hello, World!")
```
保存（`Ctrl + S`），然后用两种方式运行它：
- 点 VS Code 右上角的 ▶ 按钮
- 或者在终端里输入：
  ```bash
  python3 hello.py
  ```

看到输出 `Hello, World!`，环境就搭好了。🎉

## 知识点 1：`print`，让程序说话

`print()` 会把括号里的内容显示出来。

```python
print("Hello")
print("I am", 18, "years old")
print(3 + 5)
```

输出：
```
Hello
I am 18 years old
8
```

要点：
- 文字要用引号包起来（`"Hello"`），这叫**字符串**。
- 数字不用引号，可以直接计算。
- 用逗号隔开多个内容，`print` 会自动用空格连接。

**小实验**：把 `print(3 + 5)` 改成 `print("3 + 5")`，运行后有什么不同？为什么？

## 知识点 2：变量，给数据起名字

变量就像一个贴了标签的盒子，可以把数据放进去，以后用名字取出来。

```python
name = "Tom"
age = 18
print(name, "is", age, "years old")
```

`=` 在编程里的意思不是「等于」，而是「**把右边的值放进左边的盒子**」。

变量可以被重新赋值：

```python
score = 60
score = score + 10   # 先算右边：60 + 10 = 70，再放回 score
print(score)         # 70
```

`#` 后面的内容是**注释**，给人看的，程序会忽略它。

**命名规则**：
- 可以用字母、数字、下划线，但不能以数字开头：`age1` ✅ `1age` ❌
- 区分大小写：`Age` 和 `age` 是两个不同的变量
- 尽量起有意义的名字：`height` 比 `h` 好懂

## 知识点 3：数据类型

今天只需要认识四种：

| 类型 | 名称 | 例子 |
|---|---|---|
| `str` | 字符串（文字） | `"Hello"`、`"18"` |
| `int` | 整数 | `18`、`-3` |
| `float` | 小数（浮点数） | `1.75`、`3.14` |
| `bool` | 布尔值（真假） | `True`、`False` |

用 `type()` 可以查看一个值是什么类型：

```python
print(type("18"))   # <class 'str'>
print(type(18))     # <class 'int'>
print(type(1.75))   # <class 'float'>
```

注意：`"18"` 和 `18` 不一样！前者是文字，后者是数字。

```python
print("18" + "2")   # 182（文字拼接）
print(18 + 2)       # 20（数字相加）
```

## 知识点 4：`input`，让程序听你说话

`input()` 会暂停程序，等你在终端里输入内容并按回车。

```python
name = input("What is your name? ")
print("Hello,", name)
```

⚠️ **最重要的坑**：`input()` 拿到的**永远是字符串**，哪怕你输入的是数字。

```python
age = input("How old are you? ")   # 输入 18
print(age + 1)              # ❌ 报错 TypeError：文字不能和数字相加
```

需要用 `int()` 或 `float()` 把它转成数字：

```python
age = int(input("How old are you? "))   # 转成整数
print(age + 1)                # ✅ 19

height = float(input("Your height (m): "))  # 转成小数，比如 1.75
```

读法：`int(input("How old are you? "))` 要**从里往外读**，先 `input` 拿到文字，再用 `int` 转成数字。

## 知识点 5：运算符

```python
print(7 + 2)    # 9   加
print(7 - 2)    # 5   减
print(7 * 2)    # 14  乘
print(7 / 2)    # 3.5 除（结果总是小数）
print(7 // 2)   # 3   整除（去掉小数部分）
print(7 % 2)    # 1   取余数
print(7 ** 2)   # 49  乘方（7 的 2 次方）
```

比较运算，结果是 `True` 或 `False`：

```python
print(5 > 3)    # True
print(5 == 3)   # False  注意：判断相等用两个等号
print(5 != 3)   # True   不等于
print(5 >= 5)   # True
```

## 知识点 6：`if / elif / else`，让程序做判断

```python
score = int(input("Enter your score: "))

if score >= 90:
    print("Excellent")
elif score >= 60:
    print("Pass")
else:
    print("Fail")
```

读法：
- **如果** 分数 ≥ 90 → 打印 `Excellent`（优秀）
- **否则如果** 分数 ≥ 60 → 打印 `Pass`（及格）
- **否则** → 打印 `Fail`（不及格）

三个关键规则：
1. 条件后面要有**冒号** `:`
2. 下一行要**缩进**（按一下 Tab 键，或 4 个空格）。Python 靠缩进判断哪些代码属于这个条件。
3. 从上往下检查，**只会执行第一个满足条件的分支**，后面的不再看。

**想一想**：输入 95 时，为什么不会同时打印 `Excellent` 和 `Pass`？
